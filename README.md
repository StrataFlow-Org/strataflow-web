---

## 🌟 Overview

`strataflow-web` provides a consumer and business-ready frontend application for interacting with the StrataFlow Soroban smart contracts:
- **Wallet Integration**: Compatible with Freighter, xBull, Albedo, and Lobstr.
- **Agreement Creation Wizard**: Multi-step flow for defining milestone allocations, currencies (USDC/XLM), and deadlines.
- **Visual Milestone Tracker**: Live progress tracking, IPFS deliverable inspection, and payout approvals.
- **Arbitration Interface**: Dashboard for designated arbiters to inspect disputes and sign splits.

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the dApp.
