# Contributing to StrataFlow Web

Thank you for contributing to the StrataFlow Web frontend! This project is an active participant in the **Stellar Drips Wave**.

---

## 🛠️ Development Setup

1. Clone the repo:
   ```bash
   git clone https://github.com/StrataFlow-Org/strataflow-web.git
   cd strataflow-web
   npm install
   ```
2. Start the dev server:
   ```bash
   npm run dev
   ```

---

## 🏷️ Issues & PRs for Drips Wave

- **Low / Trivial**: UI responsive tweaks, tooltips, address formatting, typography polish.
- **Medium**: Integration with `@creit.tech/stellar-wallets-kit` modal triggers, adding transaction toast notifications.
- **High**: Dynamic Soroban RPC contract call transaction construction and simulation with Freighter wallet signing.
